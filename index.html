How it works

  • Random pick — Math.random() selects one of the quotes at random.
  • No immediate repeats — the quote on screen is excluded from the next draw.
  • Copy — the Clipboard API is used when available, with a safe fallback.
  • Share — the Web Share API opens a share sheet where supported.
  • Offline — quotes are bundled in script.js; no external API or asset is used.
